# DutyLootPreview

Adds a duty loot viewer to the duty window.

![a picture of the duty loot preview addon](./DutyLootPreview/Resources/DutyLootPreview.png)

## Development

```bash
nix develop
dotnet build DutyLootPreview.sln
```

Built plugin output: `DutyLootPreview/bin/x64/Debug/DutyLootPreview/`.
